# C++ Unweighted Shortest Path

A C++ application that implements graph algorithms to calculate unweighted shortest paths. This project was developed in Microsoft Visual Studio as part of my advanced C++ coursework.

## Features

- Represents graph structures using object-oriented programming
- Calculates unweighted shortest paths between vertices
- Uses queues to process vertices during graph traversal
- Tracks distances and paths through the graph
- Uses adjacency relationships to represent connections
- Implements graph-processing algorithms using C++

## Concepts Demonstrated

- C++
- Object-Oriented Programming
- Graph Data Structures
- Unweighted Shortest Path Algorithms
- Queues
- Vectors
- Pointers
- Algorithms

## Development Environment

- C++
- Microsoft Visual Studio

## About This Project

This project was created to apply advanced C++ concepts to graph algorithms and pathfinding. It strengthened my understanding of graph representation, queue-based traversal, and how shortest paths can be calculated within an unweighted graph.
